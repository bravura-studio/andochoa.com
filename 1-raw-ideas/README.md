# Raw Ideas Folder

This folder captures daily brain dumps, thoughts, and observations.

## How to Use
- Drop any rough thoughts here
- Don't worry about structure or polish
- The AI agents will analyze and connect these ideas
- Save images/screenshots in the `images/` subfolder

## Agent Processing
Files in this folder are automatically:
- Analyzed for topics and entities
- Connected to related content via wikilinks
- Used as input for weekly drafts

Start capturing your ideas here!
