# Great Writing Collection

This folder contains exceptional writing examples that help train the Style Learner Agent to understand quality patterns and voice characteristics.

## Structure
- `paulg-essays/` - Paul Graham essays (clarity, structure)
- `founder-stories/` - Exceptional founder narratives
- `technical-writing/` - Clear technical explanations
- `personal-favorites/` - Your top writing examples

## How It Works
The Style Learner Agent analyzes content here to:
1. Extract writing patterns and voice characteristics
2. Build quality benchmarks
3. Improve draft generation consistency
4. Learn structural preferences

## Adding Content
- Add any writing you admire
- Focus on pieces with strong voice or structure
- Include variety across different styles/formats
