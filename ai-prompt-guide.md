# AI Prompt Guide

Instructions and templates for working with AI to generate content from your content bank.

## Content Processing Workflow

### 1. From Raw Ideas to Content Nuggets
**Prompt Template:**
```
I have a raw idea: [paste idea from 1-raw-ideas/]

Please help me process this into:
- 2-3 one-liners for social media
- 1-2 key metrics or data points
- A user story or case study example

Format the output for easy addition to my content bank files.
```

### 2. From Nuggets to Article Drafts
**Prompt Template:**
```
Using these content nuggets from my bank:
- One-liner: [paste from one-liners.md]
- Metric: [paste from metrics.md]
- Story: [paste from user-stories.md]

Create a 800-1200 word article draft that weaves these elements together into a cohesive piece. Include:
- Compelling headline
- Strong opening hook
- Clear structure with subheadings
- Actionable takeaways
- Call-to-action

Save this as a draft in 3-article-drafts/
```

### 3. Content Adaptation for Different Platforms
**Prompt Template:**
```
Take this article draft: [paste from 3-article-drafts/]

Create platform-specific versions:
- LinkedIn post (300-500 words)
- Twitter thread (8-10 tweets)
- Newsletter snippet (200-300 words)
- Instagram caption (150-200 words)

Save each in 4-published-content/social-snippets/
```

## Content Enhancement Prompts

### Adding Personality
```
Make this content more engaging by:
- Adding personal anecdotes where appropriate
- Using conversational tone
- Including relevant analogies or metaphors
- Adding humor where suitable
```

### SEO Optimization
```
Optimize this content for SEO by:
- Suggesting relevant keywords
- Improving meta descriptions
- Adding internal linking opportunities
- Creating compelling headlines with keywords
```

### Fact-Checking & Research
```
Please fact-check these claims and suggest:
- Credible sources to cite
- Additional data points to strengthen arguments
- Recent examples or case studies
- Potential counterarguments to address
```

## Quality Control Prompts

### Content Review
```
Review this content for:
- Clarity and readability
- Logical flow and structure
- Grammar and style consistency
- Brand voice alignment
- Call-to-action effectiveness
```

### Audience Adaptation
```
Adapt this content for [target audience] by:
- Adjusting technical complexity
- Using relevant examples and analogies
- Addressing their specific pain points
- Matching their preferred communication style
```

## Automation Prompts

### Batch Processing
```
Process all new items in my 1-raw-ideas/ folder and:
1. Extract key insights
2. Generate content nuggets
3. Suggest article topics
4. Create social media snippets
5. Update my content calendar
```

### Content Audit
```
Analyze my content bank and suggest:
- Gaps in content topics
- Opportunities for content series
- Repurposing existing content
- Content performance optimization
```

---

*Customize these prompts based on your specific content goals and AI tool preferences*
